# llmJudgeReporting: Correctly Report LLM-as-a-Judge Evaluations

An R port of the 'llm_judge_reporting' Python package accompanying Lee
et al. (2025)
[doi:10.48550/arXiv.2511.21140](https://doi.org/10.48550/arXiv.2511.21140)
. Corrects the bias of accuracy estimates obtained from an imperfect LLM
judge using its estimated specificity and sensitivity, constructs
confidence intervals that reflect uncertainty from both the test and the
calibration data, and allocates a calibration budget between truly
incorrect and truly correct items.
